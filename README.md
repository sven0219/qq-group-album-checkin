# QQ 群相册阅读打卡统计

一个本地运行的 Chrome 扩展，把 QQ 群相册里的照片、视频上传记录整理为阅读打卡 Excel，适合幼儿园、班级和家长轮值统计。

例如，一个班有几十位小朋友，每人一个相册。家长每天上传阅读照片或视频，统计人不必逐个打开相册、抄日期、计算天数：配置一次名单，以后选择日期、点击导出即可。

**当前版本：2.1.1。分享版不内置真实群号或儿童名单，首次使用需要自行配置。** 这是非官方工具，不是腾讯提供或维护的产品，依赖 QQ 群相册网页的内部模块，QQ 改版后可能需要更新。

## 1. 插件能做什么

- 导出指定周：用日历选该周任意一天。
- 导出上周：按电脑当前日期，定位上一自然周。
- 导出连续周范围：日历选择开始日期和结束日期，自动计算覆盖的周次。
- 每周一个 Sheet，记录学号、姓名、周一至周日是否打卡，以及一周打卡总天数。
- 附带“历史明细”和“统计说明”，便于核对来源、媒体数量和统计规则。
- 每次导出自动打开/切换到对应群相册、刷新页面、扫描最新记录，无需手动扫描。
- 未登录时进入 QQ 官方登录页面；登录成功后回到群相册，再点击导出。
- 自定义班级、学期名称、学期开始日期和儿童名单，支持下学期继续使用。
- 周表采用蓝色表头、隔行底色和绿色打卡标记；只冻结表头，不冻结列。

它**不判断阅读内容是否合格**，不识别人脸，不播放视频，也不根据视频拍摄时间推算阅读日期。

## 2. 统计规则与工作原理

### 统计规则

| 情况 | 统计结果 |
| --- | --- |
| 某孩子当天上传至少一张照片或一个视频 | 当天标记 `√`，计 1 天 |
| 同一天上传多次、上传多条媒体 | 仍只计 1 个打卡日 |
| 同一天由不同家长上传到同一孩子相册 | 合并为同一个打卡日 |
| 某天没有上传 | 单元格留空，不增加总天数 |
| 完整相册目录中未显示对应相册，或相册媒体数为 0 | 按未打卡处理，并列出提醒 |
| 目录、相册或媒体读取失败 | 停止自动导出，提示错误，不把未知状态算成 0 天 |

日期依据是 QQ 返回的**媒体上传时间，按北京时间转换**。不是相册创建日期，也不是照片拍摄时间。

例如，9 月 21 日阅读、9 月 23 日才补传，插件计在 **9 月 23 日**。删除媒体后再导出，会按重新扫描时仍存在的记录计算。每周最多 7 个打卡日，默认包含周末，不自动排除节假日。

### 周次怎么算

以用户配置的“学期开始日期”所在的自然周作为第 1 周，一周为周一至周日。

例如：

- 学期开始日期为 `2026-09-01`：第 1 周是 `2026-08-31 至 2026-09-06`，第 4 周是 `2026-09-21 至 2026-09-27`。
- 下学期设为 `2027-02-22`：第 1 周是 `2027-02-22 至 2027-02-28`，第 2 周是 `2027-03-01 至 2027-03-07`。

学期名称只是标题文字，不会自动决定开学日期。若学校有自己的周次规则，请将开始日期设在学校认定的第 1 周内。当前不支持停课周跳号、假期不计周等特殊校历。

### 读取原理

```text
点击导出
  → 按群号定位群相册、刷新页面并检查登录
  → 分页读取相册目录，按名单中的相册名匹配
  → 分页读取各相册的媒体 ID 和上传时间
  → 按北京时间归日、按孩子与日期去重
  → 按学期开始日期计算周次
  → 本机生成并下载 Excel
```

扩展由三个部分协作：

1. `background.js`：管理设置、导航、扫描任务、统计和下载。
2. `content.js`：运行在扩展的隔离环境中，负责转发允许的读取请求。
3. `page-reader.js`：运行在 QQ 网页环境中，调用网页已经加载的 `photo.v7/module/groupPhoto/util/index` 模块中的 `getAlbumList` 与 `getPhotoList` 方法。

两种脚本通过限定消息类型的 `window.postMessage` 通信，检查消息来源窗口和页面来源。读取器只把相册名称/数量、媒体 ID 和上传时间交给扩展，不把媒体链接、家长昵称等作为统计数据保存。

这不是腾讯公开承诺稳定的 API，不需要用户复制 Cookie 或访问令牌，但依赖正常 QQ 登录会话和网页模块。扩展不会绕过相册访问权限、密码或验证码。

## 3. 群相册有什么要求

使用前请确认：

1. QQ 群启用了群相册，登录账号有权限查看相册和媒体。
2. 在 Chrome 中能够正常打开 `https://h5.qzone.qq.com/groupphoto/index?inqq=1&groupId=你的群号`。
3. **每位孩子对应一个独立相册**，不要把全班打卡混放在一个公共相册。
4. 相册名称在本群内应唯一；名单中的“相册名”应与网页名称一致。
5. 对应相册应专门放阅读打卡。若混入生活照片或非打卡视频，插件也会把这些上传计为打卡。
6. 图片或视频都可以，一天上传一条或多条均可，不要求特定文件名或描述。
7. 名单中学号、姓名应各自唯一。若有同名孩子，请使用可区分的显示姓名，并在第 3 列指定各自实际相册名。

**相册名不一定要等于姓名。** 例如，相册名是“示例小朋友甲阅读”，名单可以写成：

```text
1,示例小朋友甲,示例小朋友甲阅读
```

特别注意：QQ 可能不显示零媒体相册。插件在完整目录里找不到匹配相册时会按未打卡处理，**无法仅凭“没有卡片”区分空相册、相册不存在、命名错误或账号不可见**。请检查导出提示中的“目录未显示或零媒体”名单，确认不是拼写或权限问题。

## 4. 安装

建议使用支持 Manifest V3 的当前 Chrome 版本。本扩展尚未发布到 Chrome 网上应用店，需要加载已解压扩展。

1. 在本仓库点击 **Code → Download ZIP**，下载并解压。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 **`extension` 文件夹**，不是仓库根目录；该文件夹内应能直接看到 `manifest.json`。
6. 在 Chrome 工具栏的扩展菜单中，把“QQ群相册打卡统计（本地）”固定到工具栏。

安装不需要运行 npm、编译程序或购买服务。

## 5. 首次配置

点击插件图标，在“班级设置”中填写：

| 设置项 | 如何填写 |
| --- | --- |
| QQ群号 | 填你有权限访问的班级群号，仅数字，不是 QQ 个人账号 |
| 班级 | 例如“小三班”，用于周表标题和文件名，不出现在名单或周表数据列中 |
| 学期名称 | 例如“2026年-2027年第一学期”，用于标题和文件名 |
| 学期开始日期 | 用日历选择；界面会显示对应第 1 周的日期范围 |
| 儿童名单 | 展开“编辑儿童名单”，每行一位，格式为 `学号,姓名,相册名` |

名单示例（均为演示占位名称，请替换）：

```text
1,示例小朋友甲,示例小朋友甲
2,示例小朋友乙,示例小朋友乙阅读
3,示例小朋友丙,示例小朋友丙
```

- 支持英文逗号 `,` 和中文逗号 `，`，不要粘贴表头。
- 第 3 列相册名可以省略，省略时使用姓名。
- 不要在名单中添加班级列、家长姓名或电话号码。
- 当前采用文本粘贴配置，**不支持直接上传名单 Excel，也没有名单文件下载模板**。

点击“保存设置”，看到绿色“设置保存成功”提示和“✓ 已保存”按钮即完成。点击导出时，也会自动保存面板当前配置。

## 6. 登录与日常导出

### 登录 QQ

无需先手工打开相册。点击导出时，插件会优先使用当前窗口里已打开的同群相册；没有则新开标签页，不覆盖普通网页。

未登录时，QQ 的群相册请求会跳转到官方 `i.qq.com` 登录页，并带上返回群相册的地址。请自行扫码或输入账号登录，完成 QQ 要求的验证。登录成功返回相册后，**重新点击导出**；登录等待期间不会无限保留原导出任务。

### 导出指定周

1. 在“指定周中的任意一天”中选择日期。
2. 查看下面显示的周号与周一至周日范围。
3. 点击“导出指定周”。

### 导出上周

点击“导出上周”，按电脑当前日期所在周的上一周导出。例如电脑日期为 2026-09-28，上一周是 09-21 至 09-27。请确保电脑日期与时区正确。

### 导出周范围

1. 用日历选择开始日期和结束日期。
2. 检查界面显示的实际周范围。
3. 点击“导出所选日期所在的周范围”。

导出的是覆盖这些日期的**完整自然周，包含首尾周**，不是截断到选定日期：开始日期选 2027-02-24、结束日期选 2027-03-03，实际覆盖 2027-02-22 至 2027-03-07。选同一周内的两个日期只生成一张周表。

当前范围限制为学期第 1 至第 100 周，结束日期不能早于开始日期。

### 扫描与下载

每次导出都会先刷新网页并重新读取全历史，不只读取可见卡片或所选周。媒体较多时需要更长时间。

- 保持 Chrome 和群相册标签页打开，不要中途切换相册页的群号或退出 QQ。
- 新标签打开或关闭插件面板后，后台任务仍可继续；再次点击插件图标可以查看进度。
- 若 Chrome 关闭、后台任务中断或登录过期，需要重新点击导出，不保证关机后继续。
- 目录或任意孩子媒体读取失败时，不下载不完整周表，修复原因后重试。
- 下载提示包含周号与实际日期范围。

文件名形如：

```text
2026年-2027年第一学期_小三班_第4周打卡记录.xlsx
2026年-2027年第一学期_小三班_第2周至第4周打卡记录.xlsx
```

## 7. Excel 内容

| Sheet | 内容 |
| --- | --- |
| 第 N 周 | 学号、姓名、7 天日期与打卡标记、一周总天数 |
| 历史明细 | 所选周范围内按孩子/上传日期汇总的记录，含来源相册、媒体数量、采集时间与读取状态；不是逐条媒体文件清单 |
| 统计说明 | 群号、范围、扫描时间、周次规则、缺失相册提醒与各孩子读取状态 |

周表总天数使用公式，手工调整 `√` 后可重新计算。日期保存为 Excel 日期值。只冻结表头，所以仍会有横向冻结分隔线，不再有冻结列的竖线；冻结线不是额外的数据列或打印边框。

## 8. 换学期、换班级与更新插件

### 下学期

修改“学期名称”和“学期开始日期”，按需修改班级与名单，再导出。周次将重新按新的开始日期计算，历史媒体仍可根据选定日期范围读取。

### 换 QQ 群或相册改名

- 修改群号会清空插件当前群的缓存记录和读取状态，随后导出重新扫描新群。
- 相册改名后修改名单第 3 列；修改姓名或相册映射会使对应孩子的旧缓存失效。
- 孩子增减后更新名单，不要依赖上一学期的名单。

### 更新

1. 下载新版源代码。
2. 用新版 `extension` 文件夹内文件覆盖原安装文件夹中的扩展文件。
3. 在 `chrome://extensions/` 中点击该扩展的“重新加载”。

保留原安装路径、重新加载通常可保留本机设置。**不要先移除旧插件**，移除扩展会清除其本地数据。已有 Excel 不会自动变化，需要重新导出。

## 9. 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `storage` | 在本机保存配置、汇总历史、读取状态与任务进度 |
| `tabs` | 查找、打开、切换和刷新群相册标签页 |
| `downloads` | 下载本机生成的 Excel |
| `https://h5.qzone.qq.com/*` | 在 QQ 群相册网页中运行读取脚本 |

插件没有第三方统计服务，不把名单或打卡记录发送到项目作者的服务器，不读取或保存 QQ 密码，不主动批量下载儿童照片或视频。QQ 网页本身加载媒体、登录流程与正常 QQ 请求仍由腾讯服务处理。

配置与历史存在本机浏览器配置文件中，Excel 包含儿童姓名、群号及活动日期，请妥善保管。请勿把自己的导出文件、名单、页面截图、Cookie、验证码或登录信息提交到公开仓库或 Issue。分享问题截图前先打码。

## 10. 常见问题

**所有孩子都显示“未显示/零媒体”怎么办？**

检查群号、登录账号权限、实际相册名称和名单第 3 列。名字中的错别字、空格或后缀都可能影响匹配。当前不做姓名 OCR 或模糊纠错。

**某位孩子明明阅读了，为什么当天没有打卡？**

插件只能确认上传日期，不能判断线下阅读。检查是否当天上传、是否传到正确相册、是否属于所选周，以及媒体是否已删除。

**登录后还报初始化失败/超时怎么办？**

确认网页能正常展示相册，手动刷新后重试，检查网络和账号权限。仍失败时可提交脱敏错误文字和浏览器/插件版本。QQ 网页改版或风控可能需要调整读取方法。

**能否直接在 QQ 桌面客户端里使用？**

不能。扩展安装在 Chrome 中，读取的是 QQ 群相册网页，不是桌面 QQ 窗口。

**能否每天自动定时扫描或自动发到群里？**

当前不支持。必须点击导出，且有可用的浏览器登录会话；插件不会向群里发消息或上传文件。

**为什么历史明细同一天只有一行？**

按“孩子 + 上传日期”汇总，`媒体数量`表示当日读取到的去重媒体数量，打卡天数仍只增加 1。

## 11. 源码与测试

```text
extension/
  manifest.json       Chrome Manifest V3 配置
  popup.html/css/js   配置、日历、状态与导出界面
  background.js      任务、导航、统计和下载
  content.js         隔离环境读取桥接
  page-reader.js     QQ 页面元数据读取与分页
  xlsx.js            本地 XLSX 打包与工作表生成
  workbook-style.js  工作簿样式定义
tests/               使用模拟数据的本地回归测试
```

运行本地测试（Node.js 18 或更新版本，无第三方 npm 依赖）：

```bash
npm test
```

测试覆盖空默认配置、周次与跨学期日期、范围边界、XLSX 冻结设置和导出提示等逻辑。模拟测试不代替真实 QQ 登录、权限和网页兼容性验收；不要把真实儿童数据加入测试夹具。
